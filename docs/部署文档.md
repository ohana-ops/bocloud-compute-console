# 部署文档

> 本文档说明博云算力资源管理后台系统的完整部署步骤，适用于本地开发环境与私有化交付环境。

---

## 一、环境要求

| 依赖 | 版本要求 | 说明 |
| :--- | :--- | :--- |
| JDK | 17+ | 后端运行环境 |
| Maven | 3.8+ | 后端构建工具（IDEA 内置 Maven 亦可） |
| MySQL | 8.x | 业务数据库 |
| Redis | 5.x+ | 认证 Token、缓存 |
| Nacos | 3.x | 注册中心 + 配置中心 |
| Node.js | >= 8.9 | 前端构建环境 |
| npm | >= 3.0 | 前端依赖管理 |

---

## 二、中间件部署（Docker 方式）

项目 `docker` 目录已内置中间件的编排文件，可一键启动：

```bash
cd docker
docker-compose up -d
```

需要启动的中间件包括：

- Nacos（注册 + 配置中心）
- MySQL（业务库）
- Redis（缓存）

> 若使用已有中间件，跳过此步，直接修改各服务配置中的连接地址即可。

---

## 三、数据库初始化

按顺序导入以下 SQL 脚本：

### 1. 基础库脚本

```sql
-- 若依基础表结构 + 菜单 + 字典 + 初始数据
source sql/ry_20260417.sql;
```

> 建议单独创建 `ry-cloud` 数据库，并在脚本中指定对应的库。

### 2. 业务库脚本

```sql
-- 算力资源业务表 + 业务字典 + 菜单权限
source sql/bocompute_20260922.sql;
```

该脚本会创建：

| 表名 | 说明 |
| :--- | :--- |
| `biz_resource` | 算力资源表 |
| `biz_resource_apply` | 资源申请表 |
| `biz_resource_alloc` | 资源分配记录表 |

同时插入 4 类业务字典、17 条菜单（含按钮权限），并预置 5 条算力资源示例数据。

## 四、Nacos 配置初始化

### 1. 基础配置

导入若依原生的 Nacos 配置脚本：

```sql
source sql/ry_config_20260311.sql;
```

### 2. 业务配置

导入算力资源模块的 Nacos 配置脚本：

```sql
source sql/bocompute_config_20260922.sql;
```

该脚本包含：

- `ruoyi-bocompute-dev.yml`：新模块的数据源、Redis、端口等配置
- 网关路由追加：`/bocompute/**` → `ruoyi-bocompute` 服务
- Sentinel 限流规则（可选）

> ⚠️ **必须导入**：网关路由不追加，前端所有 `/bocompute/**` 请求会 404。

---

## 五、后端构建与启动

### 1. 构建

在项目根目录执行：

```bash
mvn clean install -DskipTests
```

### 2. 启动顺序（务必按序）

| 顺序 | 服务 | 端口 |
| :--- | :--- | :--- |
| 1 | Nacos | 8848 |
| 2 | MySQL | 3306 |
| 3 | Redis | 6379 |
| 4 | ruoyi-gateway | 8080 |
| 5 | ruoyi-auth | 9200 |
| 6 | ruoyi-system | 9201 |
| 7 | ruoyi-bocompute | 9400 |

各服务启动命令（示例）：

```bash
java -jar ruoyi-gateway/target/ruoyi-gateway.jar
java -jar ruoyi-auth/target/ruoyi-auth.jar
java -jar ruoyi-modules/ruoyi-system/target/ruoyi-system.jar
java -jar ruoyi-modules/ruoyi-bocompute/target/ruoyi-bocompute.jar
```

> 其他模块（gen、job、file、monitor）可按需启动，不启动不影响核心业务流程。

---

## 六、前端构建与启动

### 1. 开发环境

```bash
cd ruoyi-ui
npm install
npm run dev
```

### 2. 生产环境打包

```bash
cd ruoyi-ui
npm run build:prod
```

> 打包产物在 `ruoyi-ui/dist`，通过 Nginx 等 Web 服务器托管，反向代理 `/prod-api` 到网关 8080 端口。

---

## 七、访问验证

1. 浏览器访问 `http://localhost:80`（开发环境）。
2. 使用默认账号 `admin` / `admin123` 登录。
3. 左侧菜单应出现「算力资源管理」一级菜单及其子菜单。
4. 依次验证：资源列表 → 提交申请（普通用户）→ 审批通过（管理员）→ 分配记录 → 统计看板。

---

## 八、角色权限配置

登录后进入「系统管理 → 角色管理」：

| 角色 | 建议勾选权限 |
| :--- | :--- |
| 管理员（admin） | 默认全权限，含「申请审批」 |
| 普通用户 | 勾选「我的申请」及「统计看板」查看权限 |

> 普通用户不应勾选「申请审批」相关按钮权限，以保证「申请 / 审批」的角色隔离。

---

## 九、常见问题排查

| 问题 | 可能原因 | 解决 |
| :--- | :--- | :--- |
| 前端请求 `/bocompute/**` 返回 404 | 网关未追加路由 | 重新导入 `bocompute_config_20260922.sql` |
| `ruoyi-bocompute` 启动报连接数据库失败 | 数据源配置错误 | 检查 Nacos 中 `ruoyi-bocompute-dev.yml` 的数据库地址、账号、密码 |
| 服务启动报 Nacos 连接失败 | Nacos 未启动或地址错误 | 确认 Nacos 已启动，检查 bootstrap.yml 的 server-addr |
| 登录后看不到算力菜单 | 菜单 SQL 未导入 / 角色未授权 | 确认 `bocompute_20260922.sql` 已执行，并为角色勾选菜单 |
| Maven 依赖解析失败 | 网络 / 仓库问题 | 项目已配置阿里云 Maven 镜像，可执行 `mvn -U clean compile` |
